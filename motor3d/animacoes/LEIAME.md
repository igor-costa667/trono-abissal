# Animações do Mixamo

Coloque aqui os arquivos .fbx baixados do Mixamo (mixamo.com), com o personagem padrão (Y Bot),
formato FBX Binary, "Without Skin", 30 fps, sem redução de keyframes; "In Place" marcado para andar e correr.
O motor 3D usa esses movimentos reais no Ren (redirecionando para o esqueleto dele).
